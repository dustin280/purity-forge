No code changes needed. The **Pull from Drive** button lives at:

`/instrument-comm/openlab` → **Settings** tab → *Google Drive sync* section → **Pull from Drive** (next to *Save Drive folders*).

Clicking it saves the currently entered Methods / Sequences / Reports folder IDs, then re-indexes them via the connector. After the recent fix that limits Methods to the root `/Methods` directory, hitting this button is what refreshes the method list you see in the Run List Generator.
